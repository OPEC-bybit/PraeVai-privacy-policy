# PraeVai Privacy Policy

Last updated: September 24, 2026

PraeVai is an on-screen Thai–English translation tool designed to perform screen capture, OCR, and translation on the user's device.

## Data the app accesses

- Screen images explicitly authorized by the user through Android's system consent dialog, for recognizing and translating visible text.
- Text recognized from those images for translation and on-screen display.
- Local app preferences, such as the selected translation direction and interface language.
- An internet connection to download Google ML Kit translation models initially or when a model update is required.

## How data is used

Screen images and recognized text are used only to provide the translation requested by the user. OCR and translation run on-device after the required models are downloaded. PraeVai does not provide user accounts, advertising, or a developer-operated server that receives screen images or translated text. Google ML Kit SDKs may collect device and app information, per-installation identifiers, performance metrics, API configuration, input/output sizes, feature events, error codes, and configured or identified languages for diagnostics and usage analytics. This diagnostic data is transmitted to Google over HTTPS; it does not include screen images or recognized text content. See [Google's ML Kit data-disclosure guidance](https://developers.google.com/ml-kit/android-data-disclosure).

## Storage and sharing

- PraeVai does not persist screen images or recognized text.
- PraeVai does not send screen images or recognized text to the developer, advertisers, or other parties.
- Translation-direction and interface-language preferences are stored in the app's private on-device storage.
- Model downloads use Google ML Kit and are subject to Google's applicable terms and policies.
- Google ML Kit collects the diagnostic and usage data described above. Google states that this data is encrypted in transit and not transferred to third parties by the SDK.

## User choice and control

- The user initiates and confirms each screen-capture session.
- Android displays an ongoing notification while PraeVai runs, and the user can stop it at any time.
- Overlay and notification permissions can be withdrawn in Android settings.
- Apps protected from capture by Android cannot be read or translated.
- Uninstalling PraeVai removes its locally stored preferences.

## Security and children

PraeVai is not designed to collect personal information and has no account system. Screen content may nevertheless contain sensitive information. Users should run capture only when needed, stop the session afterward, and avoid password, financial, or sensitive health screens.

## Changes

This policy will be updated, including its revision date, if PraeVai's functionality or data practices change.
